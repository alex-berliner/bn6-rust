## Step 2 — Find what the dangling 1270 citation rests on.

`tools/allowlist.py:42` says "TODO A8, the custom gauge's stripe-flow animation not yet
modelled (TRANSFER.md 1270)". Section 1270 does not exist (TRANSFER.md's headings all have
ids like "7a", "7ab"...), so 1270 is a LINE NUMBER. The content the comment is pointing at
is in section 7bl (lines 1272-1275):

> WHAT IS LEFT is the custom gauge (TODO A8): 470 px, all of it the flowing bar and its
> L-or-R marker. Not a fill -- the lit-pixel count cycles through the same four values
> throughout. Not a phase -- no offset in its 112-frame period helps. The four-state flow
> this build models is right for the settled state; what is missing is that early on the
> stripes SHIFT position as well as cycling, and something stops that around frame 98 of
> the capture.

So `TRANSFER.md 1270` is the LINE of that paragraph, and it lives in section 7bl. The
allowlist entry's claim rests on a measurement of 470 px (8-frame period, settled flow
correct, shift missing) — which is consistent with what the harness currently reports and
with the tile/gauge integrated worst=3468 in the same comment block. So the citation IS
proven; it just cited a line number rather than a section id. The provenance entry will
record both: the section id (7bl) and the line range (1272-1275).

## Dangling 1270 — answer.

`tools/allowlist.py` cited "TRANSFER.md 1270" but no section by that id exists. 1270 is
a LINE NUMBER in section 7bl (lines 1272-1275), which is the home of the TODO A8
custom-gauge stripe-flow fact. The citation is **proven**: the same comment cites
`worst 3468/8 frames` and section 7bl measures 470 px of stripes on tiles/gauge
integrated, which is the same defect (the harness's worst-frame matches what 7bl
describes). The provenance entry is `docs/provenance.md#7bl` with the line range
noted in the body.
