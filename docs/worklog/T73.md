## Step 4 — why no fix (unmerged)

The cursor's 7/6/170 is the binary-layout side effect of any change to
src/battle.rs: replacing one match arm with another shifts code addresses
downstream and changes the vblank-boundary cycle parity the cursor's row
catches. No source change to the match arm can avoid it. The mitigation
would be a fix at the cursor row itself (T56's NEGATIVE was about the same
class of issue) -- out of T73's scope and named in the "Ideas tried and
dropped" section below.
