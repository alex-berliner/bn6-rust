## Mechanism, one line

word_3007924 (asm38.s:4242-4249) carries one u32 per panel type 0..12
(9 distinct words; types 9..0xC share 0x10210), OR'd into
oPanelData_Flags by `_object_updatePanelParameters` at asm38.s:4213-4219;
the rust side never reads or writes this OR path because no
fixture/panel-step code path consumes it.

## Unverified, one line

No harness row exists to measure a non-type-5 panel-step; no
descriptor field pokes `oPanelData_Type`; the flag-word OR lever
is bounded as a fixture gap, retiring the M3 OR-flag port.
