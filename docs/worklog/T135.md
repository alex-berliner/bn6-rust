## VERDICT (read first)

**The 587 px/frame is a RECOLOUR, not a new body.** Poking the transformation
byte (0x0203ce2c = oNaviStats_Transformation) to TF_HEATCROSS leaves canon's
OAM **byte-identical every frame** and swaps OBJ bank 0 from palette row 0 to
**row 2 of the same battleSpriteMegaMan palette blob** at the first frame
after the poke. Canon's selector is `sub_801002C` (asm00_2.s:2776-2779) ->
`byte_80203EA[TF]`, applied by `sub_80100EC` (:2789-2804) via
sprite_setPalette. All ten crosses (TF 1..0xa) share the BASE body set
(`byte_800FCBC` maps them onto category 0, sub_800FC9E :2201-2215) — the art
was resident all along; only the palette rows had to ride along in the asset.
Ported: **form_cross isolated PASS 0/0/40, negative not blind (644), fitted 17.**

   read called it "bank 16", off by the palette-RAM base) calm = megaman blob

   Full-frame canon-vs-canon over the window: **51240 total, 1281/frame** =
   T123's 694 (face) + 587 (body) exactly.
2. **OAM decode** (frame 50): body = objects 6..9 (x41..81, y70..118, bank 0,
   prio 2); face = objects 0/1 (bank 12, tiles 0x3b4/0x3bc) — matches T123's
   region x≈50..79/y≈70..119.
3. **byte_80203EA** (@0x080203EA, ROM bytes): TF 0..0xa -> `0,2,7,9,d,13,5,
   11,b,f,15`; indices >0xa all 0x00 (only cross values index the table —
   sub_801002C :2773-2779 excludes 0/0xb/0xc).
4. **byte_800FCBC** (@0x0800FCBC, ROM bytes, via sub_800FC9E): MegaMan's
   sprite category = TF 0..0xa -> 0 (crosses share the base set!),
   0xb->0xB, 0xc->0xC, 0xd..0x16 -> 1..0xA, 0x17/0x18 -> 0xB/0xC. The
   battleSprite*Cross blobs are the CROSS-BEAST bodies; the TREZ

## The port

- `assets/megaman.bin` re-exported `--palettes 21` (26662 -> 26854 bytes;
  22 palettes; row 21 byte-verified against the ROM blob) so
  `Player::palette_add` reaches every row byte_80203EA names.
- `src/battle.rs`: reads the byte once at battle build (canon reads it at
  init; the load poke is the only writer on this route) ->
  `cross_form_palette_row` (byte_80203EA, 11 entries, provenance derived) ->
  `megaman.set_form_palette_row(...)`.
- `src/actor.rs`: `form_palette_row` field + `set_form_palette_row`; the warp
  pale-expiry restores the form row instead of 0 (canon re-stages the row
  every frame, stageObjPalette_8002818).
- `tools/harness.py`: `form_cross` (emotion_syn route + the poke both sides +
  the emotion_skip face pin on canon + emotion=5 descriptor on ours — face
  emptied BOTH sides, body isolated; no landed row moved). `tools/states.py`:
  `form_cross_full` scenario. `tools/inventory.py`: TF_HEATCROSS status ->
  "recorded (form_cross)".
- **After**: form_cross isolated **PASS 0/0/40**, negative not blind (644);
  fitted 17 (derived 437, peeked 146). Trace `form_cross_full`: mm_anim match
  40/40; mm_state_action canon=(4,21) rust=(4,8) from k=0 — the route's
  documented pre-existing pairing (docs/coverage/emotion.md pass 5: "canon's
  chip-cast action code vs our equivalent; pixels identical"), no new
  divergence; enemy_* fields ride the same route pairing; sequencer/mm_panel/
  mm_timer/rng_cadence match.
