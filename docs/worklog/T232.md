  containers) for that 448-byte blob: ONLY index 1 (0x241EC4) contains it. The v1
  sheet 0x242E94 (idx 2) matches nowhere in tiles 0..63.

  brightened variant (entries 2..6,13..15 differ; 0x842/0x3d6a/0x2907/0x14a5 shared),
  constant f100..f199. Consistent with actor.rs:47 WARP_PALETTE=1, our existing
  materialize pale-frame mechanism.
