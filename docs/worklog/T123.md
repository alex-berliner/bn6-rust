## Step 1 — the canon ROM watch (measurement)

`possiblyGetBattleEmotion_8015B64` reads the transformation from the battle
NaviStats: `GetBattleNaviStatsAddr` (asm00_2.s:10159) = eBattleNaviStats0
0x0203ce00 (ewram.s:3109) + alliance*0x64, `oNaviStats_Transformation` = 0x2c
(include/structs/NaviStats.inc) → **0x0203ce2c** for the player. The resolved
slot is stored at eStruct+0x10/+0x11 = 0x02035290 (:27341-27342); the blink
countdown is +0xf = 0x0203528F.

Recipe = emotion_syn's canon side (STERILE, PAUSED state, chip b1 cast,
A@40, --disable-bg). `probe.py watch`, 100 capture frames:

| addr | bytes | read |
|---|---|---|
| 0x02035290 | slot halfword | 0x0002 every frame (Unk_32 poke → enum 1 → slot 2) |
| 0x0203528F | blink countdown | **0x00 every frame 0..99** |
| 0x0203ce2c | transformation | 0x00 every frame |
| 0x0203528e | (T122's "beast-out counter" byte) | 0x03 every frame (NOT 0; T122's halfword poke 0x0203528e:0x0500 zeroed it mid-window — harmless there, but the "reads 0" claim was wrong) |

So on the descriptor route the countdown never leaves 0 — the `cmp #6/cmp #5`
blanking phases (asm00_2.s:27648-27652) never fire in the compared window.
T105's note "blink frames canon 2..11" predates the marker alignment; on this
recipe the countdown is flat 0.

## Step 2 — reaching the cross state on the descriptor route (measurement)

- `--watch-write 0x0203ce2c` over the same 100 frames: **zero writes** — canon
  never writes the battle transformation byte during the window (battle init
  had already run inside the save state), so a load `--poke` survives.
- Poke `0x0203ce2c:0x0001` alone: slot halfword reads **0x0005** on every
  frame 38..99, countdown still 0x00 → canon draws the slot-5 face on all 40
  compared frames. Cross state reached; the window HOLDS on that face.
- Lesson (measured, dropped): poking Unk_32 ON TOP of the transformation poke
  lands slot **0x000a** — enum 1 → byte_801E6F4[1]=2 → the full-synchro +5
  (sub_801E6A8 asm00_2.s:30975-31001: transformation 1..10 +5 when
  byte_801E6F4[enum]==2) fires on 5→10. The cross row must NOT carry the
  Unk_32 poke its siblings carry.
- Slot 6 is `byte_801E700[2]` (transformation 2); one slot value exercises the
  rule, the arm covers both by the same table.
- Where canon writes it: nowhere on this route (watch-write, above). Canon's
  writers are elsewhere (cross/beast activation, save data); not chased
  further — the descriptor route only needs the byte to hold, which it does.
