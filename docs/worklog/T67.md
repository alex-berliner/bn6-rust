## Step 2b — but the tail is CONDITIONAL: battle_full does NOT show it

`frame=303 old=0x0000 new=0xFFFFFFFF at=0x08017586` (matching T63's "canon frame 303 (k=292)"
exactly); NO store lines after it. Value bin (--watch, lossy-proof): frames 295..302 countdown

- PAUSED route (STERILE+PAUSED+ALIVE+Start@10): phase INIT fires -> tail 9..0 (measured f138..147)
- battle_full (REAL+PAUSED+custom-screen script): phase INIT does NOT fire -> sentinel holds

The gate must sit on the dispatch path before JumpTable80EA7B0 — the only branch sites are
playerAI_update_80EA734's early-outs: battle_isBattleOver, GetAIData_Unk_44_Flag & 0x8600 ->
sub_801056A(0,0)+return (NO jumptable dispatch), & 0x80000 -> object_setAttack0(0x49)+return.
Which condition differs between the scenes is NOT resolved (candidate: the custom-screen episode
in battle_full's script sets an AIData+0x44 bit; the PAUSED route never opens it). Ideas for the
follow-up: capture AIData+0x44 (player AIData block ~0x020340xx, +0x44) on both scenes, or

MODEL CONSEQUENCE: the tail is real, attributed, and reachable on the PAUSED route (the mettaur

## Model decision (step 3) — model the writer, values unchanged, provenance now derived

The census names a reachable player-slot Timer writer (playerAI_sub_80F0354, MEASURED firing on
the PAUSED route), so per the ticket the writer is modeled in src/actor.rs. Its export values are
IDENTICAL to main's old fitted shape — the fitted constant was fitting the real mechanism — but
the numbers are now derived, not fitted:

- `POST_FLINCH_FRAMES: u8 = 11` (fitted) -> `PHASE_ARM_FRAMES: u8 = 10` (derived:
  asm31.s:118977-118978 `mov r0,#0xa` / `strh r0,[r5,#oBattleObject_Timer]`) plus
  `SENTINEL_FRAMES: u8 = 1` (derived: the underflow frame itself, asm00_2.s:18353-18355).
- `TIMER_SENTINEL: u16 = 0xffff` (derived: asm00_2.s:18353-18355) with the conditionality in its
  tag: one frame on the PAUSED route, holding 303..339+ in battle_full.
- field `post_flinch` -> `phase_arm_shadow` (the mechanism it shadows is now known);
  export arithmetic unchanged: shadow==SENTINEL+PHASE_ARM -> TIMER_SENTINEL, else shadow-1,
  gated on Action::Idle, armed at the flinch exit, saturating tick in update().
- `oracle_fields` Timer bullet rewritten (was "fitted -- ... not derived from a cited
  instruction"); src/battle.rs:1696's mm_timer comment renamed; docs/coverage/battle_full.md
  gained the T67 section stating the conditional hold, the attribution, and the gate as an
  explicit NEGATIVE (gate unidentified; candidates = playerAI_update_80EA734's AIData+0x44
  0x8600/0x80000 early-outs, asm31.s:107357-107447; follow-up: capture AIData+0x44 on both
  scenes or --trace-pc 0x080EA764).
