## Step 1+3: Rust table + named puts (src/battle.rs), wrapper word stores + compile-time bound (src/main.rs)

- `ORACLE_LAYOUT: [(&str, usize, usize); 19]` at module scope in src/battle.rs: the
  16 written fields PLUS mm_gap (17,1), enemy_gap (27,1) and padding (34,6) as entries,
  so the table tiles the whole 40 and the compile-time check is a full-tiling check:
  `oracle_layout_tiles` (const fn, cursor walk) + `const ORACLE_LAYOUT_OK: () = assert!(...)`
  -- cannot fold away, a bad edit fails the build.
- `OracleField` enum (discriminant = table index), `put_oracle`/`put_oracle_u8/16/32`
  named puts; oracle_snapshot rewritten with one named put per field, zero `b[` left
  (grep-verified). Gap/pad entries are listed but never written (b starts zeroed).
- main.rs `BattleMarker::put_bytes` now does word-wide volatile stores when the transfer
  is word-aligned (offset%4==0 && len%4==0): restores the single-`str` stores for the
  marker words at 0/4 (Q3 verifier note 1) and gives the 40/64-byte block writes word
  stores too. Still ONE unsafe block in the file. Runtime `assert!` kept as backstop
  (Q3 measured it cheaper than debug_assert), but the load-bearing bound is now the
  compile-time `ORACLE_REGION_FITS` const assert in main.rs
  (`ORACLE_OFFSET + ORACLE_SNAPSHOT_LEN <= BattleMarker::LEN`), twin of the tiling
  check (Q3 verifier note 2).
- ORACLE_SNAPSHOT_LEN made pub(crate) for that bound.
