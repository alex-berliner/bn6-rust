## Step 3 — state file pa_chipselect_state (DONE)

T71 left /tmp/pa_chipselect.state on disk: ONE-byte patch at file offset 0x5DDC0 (the
high byte of one folder word from 0x05 → 0x01 — confirmed by byte-by-byte diff vs
chipselect.state). Real BattleSettings + eBattleFolder reads keep the state byte at
0x020366F2 canonical (the patch is a deck-card-content swap, not a flags poke).

tools/states.py gets a new `patches` field on State: a tuple of (file_offset, byte)
pairs the build path applies to the source state byte-wise. pa_chipselect_state:
root=False, rom=REAL, base=CHIPSELECT, frames=0 (no mgba_capture run needed — copy
+ patch), patches=((0x5DDC0, 0x01),). The recipe is reversible (the source state is
unchanged) and works without a mgba_capture invocation, so `frames=0` in the build path
becomes a no-capture case: build() reads base, applies patches, writes to state.path.
