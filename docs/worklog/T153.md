## Step 2 — Canon cites (T145 / T151a reuse, no re-hunt)

Per ticket rule "Use the cite from T151a — do NOT re-hunt sub_800EC80":

- `sub_800EC80` (object.s:6066-6133): takes `enemy_idx` (u16, the quad
  byte); calls `sub_8000E30` + `sub_8014150` (= the PET's NaviCust
  rank-up bytes 0x38/0x37), takes `max`, then looks up
  `VerActorTyAIIdxTable_80182C4[3*enemy_idx]` via
  `GetVerActorTyAndAIIdx_80182B4` (asm00_2.s:20021-20028).
  - For ActorType=0 (virus) AND version<5: returns
    `enemy_idx + min(2*X, 5-version)`. On a fresh save X=0 → bump
    dormant → identity unchanged.
  - For ActorType=1 (navi) AND version<2: returns
    `enemy_idx + min(X, 2-version)`. Our case (version=0) gives the
    same `enemy_idx + min(0, 2) = enemy_idx` (identity unchanged).
  - For everything else (player, version-bumped, etc.): returns the
    input unchanged (`loc_800ECD2` → `mov r0, r4`).
  - KEY: for our slot 0x185 (version=0, ActorType=1 navi), the
    function is the IDENTITY. The "quad byte" the ticket names is
    the EnemySetup's `enemy_idx` field itself; sub_800EC80 just
    passes it through for the navi case. That makes the join
    simpler than the mettaur case (T151a): the rust side only has
    to detect "this is a navi" and read its struct columns.
- `byte_80182C4[3*0x185]` (T145 cite, ROM-read): (00, 01, 17) =
  (version=0, ActorType=1=navi, AIIndex=0x17=ForGunner_8113078).
- `byte_81067FC` (T145 cite, asm31.s:123497, ROM-read):
  `00 0B 01 01 17 00 00 01`. Struct1 layout per enemy_getStruct1
  (asm00_2.s:634-645): `[sprite_idx_hi, sprite_idx_lo, Unk_03,
  Unk_04, AIIndex, Element, SecondaryElementWeakness, HasShadow]`.
  Sprite index = `0x00*0x100 + 0x0B = 0x000B` → `naviBattleSpritePtrs[0x0B]`
  = `battleSpriteProtoMan` (data/SpritePointersList.s:73). The
  asset file `assets/protoman.bin` already exists in the project,
  used by Colonel's row.
- `byte_8106804` row 0 (T145 cite, asm31.s:123548, ROM-read):
  `84 03 00 03 0A 00` → elem_hp `0x0384` (low 12 bits) = 900,
  element `0x3>>0` = 3; canonical navi spawn HP. Already named
  `NAVI_COL_STRUCT2_ROW0_HP` in `src/navi.rs`.
