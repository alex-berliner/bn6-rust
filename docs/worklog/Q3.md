# Q3 — one safe wrapper for the boot mark and the state block (2026-09-15, worker-hyper)

Branch `wt/q3-safe-region`, HEAD 2f32355.

## Change
`src/main.rs` only. New private type `BattleMarker` owns all raw access to
`BATTLE_MARKER`; it exposes `put_u32(offset, v)` / `put_bytes(offset, &[u8])` with the
bounds contract (offset + len <= 256, the array's own size) checked by a runtime
`assert!` inside the region's ONE remaining `unsafe` block. `write_battle_marker`
routes through `put_u32(0/4, ..)`, `write_oracle_block` through
`put_bytes(ORACLE_OFFSET, ..)`, `write_trace_block` through `put_bytes(TRACE_OFFSET, ..)`.
`fixture_ptr()` keeps its address but drops its unsafe block (`&raw const` +
`wrapping_add`, both safe; the volatile reads stay in fixture.rs).
Offsets ORACLE_OFFSET=8 / TRACE_OFFSET=128 untouched; tools/oracle.py and
tools/trace.py not edited; no field-per-offset shape (Q4's work, not done here).

- after: 3 lines = 2 attribute lines (required by edition 2024, not blocks) + **1 unsafe block**

## Variants tried and dropped (all measured on this exact change)
1. runtime-offset `put_bytes` + `assert!` (chosen): .text +280, .rodata +124.
2. runtime-offset + `debug_assert!` (release no-op): .text +6852 (!), .rodata +304,
   `main::inner` +6316 — fat LTO inlines harder without the panic cold path. Worse.
3. const-generic `put_bytes::<OFFSET, N>` with inline-const compile-time bounds
   (zero runtime check, zero panic code): .text −1820, .rodata −20, but full layout
   reorder (166823 .text bytes differ, .rodata reordered, iwram/ewram pointers move).
   Cleanest contract but fails the strict byte-diff bar hardest; dropped.
