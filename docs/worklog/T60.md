## Step 2 — canon A/B, BLIND poked on the enemy

Load-time `--poke` does NOT work: at state load the CollisionData is stale
(0x0203867c reads 0x02000000, an address); the struct is initialized during
capture frame ~31 (flags word reads 0x02000000 through frame 31, 0x02400000
from 32 on). The poke must be a one-shot `--poke-at` after init.

The BlindTimer poke is REQUIRED, not optional: the tick (object.s:5512-5519)
decrements BlindTimer and, when the decremented value fails `bgt` (0-1 =
0xFFFF = -1 signed), clears 0x2000 the same frame. BlindTimer=0 → the bit
dies instantly.

Recipe (frame 40 = after init, before the compared window):
```
--poke-at 40:0x0203867c:0x2000 --poke-at 40:0x02038660:0xffff
```
Peeked on the poked run: frame 45 flags 0x02402000 / timer 0xfff9; frame 60
0x02402000 / 0xffea — one decrement per frame, bit held.

**Result (240 frames, both captures /tmp/t60_ca un-poked, /tmp/t60_cb poked):**

- frames 0..138: **0 px on every frame** (the poke is inert until the decide
  gate first re-reads the flags — a 130-frame capture reads 0 total, which is
  exactly the trap: size nothing from a short window)
- first divergent frame **k=139**, 101 diverging frames (k=139..239)
- **total 262,824 px, worst 4,972 at k=238**
- region: top half (0,0,240,80) 6,823 px; **bottom half (0,80,240,160)
  256,001 px** — the Mettaur's own panel/sprite area; k=150 bounding box
  x 164-199, y 68-144
- diffmask rendered: /tmp/t60_mask.png (k=150)

So the bit IS pixel-visible on this enemy — but see step 3: the visible
consequence is the decide/wander gate, NOT the render-hide gate.

## Step 3 — what the asm does (all read from disk this session)

**Setter/tick** `sub_800E730` (object.s:5282; BLIND arm 5512-5537): per frame
decrement `CollisionData.BlindTimer`; on expiry `object_clearFlag(0x2000)`,
zero the timer and [CollisionData+0x4c]; while held, the chip path (arg bit
0x20 set, after `object_clearFlag2`) re-sets 0x2000 (5530) and, if
[+0x4c]==0, r4=1 → `sub_80E09EE` (a sound/anim one-shot). Same block handles
CONFUSED (set 0x8000 @5483) and IMMOBILIZED (timer Unk_22, 5494-5510).

**The pixel consequence measured in step 2** runs through the decide chain:
`MettaurDecideCheckStatusAndRow_810A004` (asm31.s:171356): `object_getFlag`;
IMMOBILIZED (1<<0xe) tst @171386-171389 → return (stands still); 0xa000
BLIND|CONFUSED tst @171395-171397 → decide state 8 =
`MettaurDecideConfused_810A0BA` (random-direction hop, the AI's only RNG roll,
0x32 wait, roll &0xf < 2 attacks). The blind Mettaur wanders instead of
attacking — that is the 262,824 px from k=139 (canon's second decide
re-entry; attacks at ~32/138/244 per the mettaur row's own notes).

**The render gate** `blindVisualHandledHere_8016934` (asm00_2.s:16799-16889)
and `handleRenderBlindForSpecificObjectsMaybe_80169BE` (:16891-16952): per
frame, unless `battle_isTimeStop`, re-assert oObjectHeader_Flags bit 1
(OBJECT_FLAG_VISIBLE); DEAD (0x100) early-out and the INVIS|FLASHING (0x202)
+ FlashingInvisTimer-bit2 blink in the first routine only; then for a
CROSS-SIDE object (`oBattleState_Unk_0d ^ alliance != 0`):
`battle_findPlayer(alliance ^ 1)`'s flags & 0x2000 clears VISIBLE → the
object is not drawn. NOT alpha, NOT palette — pure draw suppression. It
tests the OPPOSING PLAYER's bit, so an enemy-side poke exercises it on
neither side; a player-side poke (0x0203a9b0's CollisionDataPtr @0x0203aa04)
is the fixture that would hide the Mettaur. Callers: per-enemy-type render
routines (Mettaur's sub_80C1094 at asm31.s:19561; also asm31.s:19790, 42680,
43202, 61640, 61777, 63619, 63650, 64024, 64071, 74003, 74031; asm32.s:3389,
3620, 13945) and the common path asm00_2.s:23679/23978 — "SpecificObjects" =
the per-type render handlers that choose to call it.

## Port design for whoever lands steps 4-5

- src/objects.rs: the four consts (CollisionData.inc:14-18 cites) replacing
  `BLIND_OR_CONFUSED: bool = false` (:352) — `think()`'s ROW arm already
  implements the whole wander machine (sub_810A0BA's roll `rng.positive()
  & 0xf < 2`, the 0x32 wait); it only needs the real flags word.
- Actor (actor.rs) gains the flags word + blind_timer (ObjectFlags1 low half
  / BlindTimer), ticked in `update()` per object.s:5512-5521.
- Delivery: our ROM has no BattleObject mirror — a harness poke needs a
  mailbox: define two halfwords (flags bits / BlindTimer) at an unused EWRAM
  address (BATTLE_MARKER owns 0x02000000..0x020000FF, INTERRUPT_TABLE
  0x02000100, SPRITE_LOADER 0x020001a8 — use the top of EWRAM, e.g.
  0x0203FFF0, and prove freeness with `nm` on the built ELF), polled in
  Actor::update, applied on change. Row: rust Side `pokes_at` + canon Side
  `pokes_at` with the step-2 recipe.
- Row window: 90 frames over the divergent region (canon ~140..229), negative
  = unpoked pair (non-blind, reads the mettaur row's known non-zero residue).
  WARNING: our wander port was never pixel-verified (canon arms the hop from
  sub_810A0D4 one frame later than our ROW-arm comment claims); expect an
  A/B against canon's wander, not a guaranteed 0/0.
- Render-gate wiring blocker: the cross-actor hide needs the player's flags
  at the enemy's draw/update; the draw loop lives in src/battle.rs (T59's
  file). Within actor.rs/spr.rs only, the gate is expressible as a
  `spr::Player` visible flag + a second mailbox halfword standing in for
  `battle_findPlayer`'s result — or the wiring lands with battle.rs.
