# T225 — emotion blink port: win `emotion_skip` back by mechanism

Branch `wt/t225`, worktree `/tmp/bnwt/t225`, base 64b968e (main tip). Ticket:
transcribe `drawEmotionWindow_801CDEC`'s blink test so the 0x0203528F countdown,
not the static 5/6 arm choice, blanks the face. Files named: `src/emotion.rs`,
`docs/coverage/emotion.md` (plus the wiring the mechanism forces: descriptor
byte +64 in `src/fixture.rs`/`tools/harness.py`, the two call sites in
`src/battle.rs`, and the row's negative fixture).

## Step 0 — canon cites (read before editing)

- Drawer/gate: `drawEmotionWindow_801CDEC` (csrc; asm00_2.s:27757-27782 — the
  ticket's :27554-27583 and :27648-27652 are pre-rename line numbers). The gate
  is `ldrb r0,[r5,#0xf]` (:27759), `cmp r0,#6; beq locret` (:27762-27766), `cmp
  r0,#5; beq locret` (:27767-27768): countdown 5 or 6 emits NO OBJ. r5 =
  eStruct2035280, so the gate byte is 0x0203528F.
- Updater: `updateEmotionWindow_801CADC` (asm00_2.s:27377-27427 — ticket cited
  :25577, pre-rename) ends with `bl sub_801CC94` (:27426).
- Countdown owner: `sub_801CC94` (asm00_2.s:27619-27685). Active arm (cycle
  counter r5[0x1d] != 0, :27621-27623 / :27666-27685): decrement r5[0xf] per
  updater frame (:27667-27669); when it wraps through 0, decrement r5[0x1d] and
  reload **0xc** (:27671-27675). The ARMING store of the same 0xc sits at
  :27655-27656 (RNG-gated: `GetPositiveSignedRNGSecondary & 1 + 1` arms
  r5[0x1d], period timer r5[0x38] reloads 0x14 = 20, :27658/:27664). The blink
  overlay queue off bit 1 of the PRE-decrement countdown is :27677-27683.
- T123 (docs/worklog/T123.md) already measured everything this ticket needs:
  the countdown reads 0x00 flat on every descriptor route (the blink never
  arms there), the slot-5 face renders pixel-exactly once the static arm is
  deleted (its A/B: emotion_skip 0 -> 27760 = 694x40, exactly the face box),
  and the supervisor's ruling predicted this ticket: "the 5/6-arm deletion can
  land together with the emotion_skip redesign it forces".

## Design (settled before editing)

1. `src/emotion.rs`: delete the static `emotion == 5 || emotion == 6` no-sprite
   arm; slots 5/6 build sprites from FACE_INDEX[5]/[6] like every other slot
   (T123 verified the slot-5 render is pixel-exact). The `Emotion` struct gains
   the modeled eStruct bytes: `blink_countdown` (+0xf) and `blink_cycles`
   (+0x1d). `show` gates on countdown 5/6 (the transcribed drawer test);
   `update` ports sub_801CC94's ACTIVE arm (decrement, wrap-reload 0xc). The
   ARMING path (timer +0x38, r5[0x15]/0x17/0x1e conditions,
   GetPositiveSignedRNGSecondary) is NOT ported — porting it would consume RNG
   and needs sub_80103EC/sub_800FE52; on every compared route canon's countdown
   is flat 0x00 (T123 100-frame watch), so the cycle counter stays 0 and the
   active arm never fires yet. Nothing fitted: the period 0xc is transcribed
   from :27655-27656/:27674-27675.
2. Countdown input: the descriptor is FULL (64 bytes, every offset spoken
   for). Extend FIXTURE_SIZE 64 -> 66 with a new byte +64 `blink_countdown`
   ("NOT IN FIXTURE.md" precedent, same as +63 emotion): the initial value of
   the ported countdown byte, 0 = the never-armed default every existing row
   already behaves as. mgba_capture takes 64 cheats; 33 is fine.
   emotion_skip's and form_cross's rust descriptors get blink_countdown=5,
   mirroring canon's at-load poke 0x0203528e:0x0500 (nothing writes the byte
   on either side afterwards — measured on canon by T105/T122, and the port's
   active arm never fires).
3. Negative fixture: the harness's negative kinds (frame/pixel shift) cannot
   zero the ported write. `Check` gains `negative_rust` — an alternative rust
   Side run as a THIRD capture at the row's own align; emotion_skip's is the
   same descriptor with blink_countdown=0. Zeroing the ported write must make
   the row read the face (T123's measured 694/frame profile).

## Step 2 — the change (all landed on wt/t225)

- `src/emotion.rs`: the static 5/6 no-sprite arm DELETED (slots 5/6 build
  sprites from FACE_INDEX[5]/[6] + their own palettes, exactly like every
  other slot). The struct gains the modeled eStruct bytes `blink_countdown`
  (+0xf, init = descriptor +64) and `blink_cycles` (+0x1d, init 0). `show`
  gates on countdown 5/6 (canon asm00_2.s:27762-27768); `update` transcribes
  sub_801CC94's active arm (decrement per updater frame, wrap-reload of the
  canon period 0xc from :27655-27656/:27674-27675). The T105 cross-face swap
  branch (FACE_INDEX + per-face palette) is untouched.
- `src/fixture.rs`: descriptor +64 `blink_countdown` (FIXTURE_SIZE 64 -> 66 in
  the harness to cover it; +65 spare). 0 = the never-armed default.
- `src/battle.rs`: `Emotion::new` takes the countdown; `battle.update` calls
  `self.emotion.update()` while `hud_live` (canon dispatches the updater while
  element 14 is enabled, the same mask bit `hud_live` models).
- `tools/harness.py`: FIXTURE_SIZE 66; `fixture_cheats` writes buf[64];
  `_chip_rust` gains `blink_countdown`; emotion_skip's rust side is
  `emotion=5, blink_countdown=5` (the descriptor mirror of canon's
  0x0203528e:0x0500 poke) with a NEW `negative_rust` Check field -- the
  negative is a third capture whose rust descriptor zeroes the ported write
  (blink_countdown 0); form_cross's rust side also gets blink_countdown=5
  (its canon side already pins the countdown with the same poke).
- `src/main.rs`: SEAM_PHASE_PAD_ITERS 25 -> 20 (see step 3).
