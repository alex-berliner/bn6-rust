`rollRandomEncounter_80AA4C0` (asm/asm29.s:10133-10325). Gate chain in order:

**THE OPT PATH (the family-A index lever, asm29.s:10216-10234).** After the threshold and BEFORE
any table walk: if `oS2001c04_Unk_28` (u32 @0x02001c2c, S2001c04.inc:23) is nonzero AND
`GetPositiveSignedRNG()` bit0 == 0 (asm29.s:10220-10222) AND `oS2001c04_OptCurBattleDataPtr`
(u32 @0x02001c30, S2001c04.inc:24) satisfies `(ptr >> 0x18) == 8` (asm29.s:10224-10230), the roll
executes `str r0,[r7,#oGameState_CurBattleDataPtr]` (asm29.s:10233) and returns that pointer:
**the game itself adopts a pre-chosen BattleSettings record wholesale -- any 0x08-prefixed record,
family A included, with no root walk, no rec7 gate, no count.** Both words are RAM the overworld
never otherwise touches on this route, so three halfword pokes field any family-A record through
the roll's own front door.
