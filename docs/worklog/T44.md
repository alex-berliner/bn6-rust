## What would close this

1. Extend `tools/oracle.py` to accept a non-harness scenario name (battle_full,
   popup, result) by routing through `states.TRACE_SCENARIOS` instead of
   `harness.run()`. The oracle block (`0x02000008:40`) is the same; the Sides are
   `Side(rom=bn6f_real.gba, script=...from states.py...)` not the harness
   descriptor. This is mechanical — the field map and FIELD_PAIRS are reusable.
2. Fix `tools/trace.py:56` so `O.MM_ORACLE_ADDR` is coerced to str before
   `int(..., 0)` (one of: `str(O.MM_ORACLE_ADDR)` or remove the `, 0` base).
3. Capture a battle_full canon/rust frame pair (530-frame scenario) and store in
   `/tmp/pf_canon_battle_full/` and `/tmp/pf_rust_battle_full/` so `diffmask.py`
   can iterate per-frame diff over 170..200, 195..250 etc.

Until 1-3 land, the ticket's stated command is structurally un-runnable and the
substitute tools can only report a mettaur-shaped signal (which is green 0/0/70
on this HEAD).
