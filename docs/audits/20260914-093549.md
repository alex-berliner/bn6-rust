## 1. Gate the model verifier to landed branches with forward claims (kills ~2/3 of verifier dispatches)

**Observed pattern.** The loop text (§3) already says a harness-only DONE needs no verifier and limits the `verifier` role to "claims beyond harness lines … or any partial/blocked/negative outcome the next ticket would build on". In practice the second clause fires on everything: the ledger shows ~25 verifier dispatches in 24h, including pure-harness DONE namings (`F12` ×8: 13:16, 18:05, 18:50, 19:14, 19:57, 22:22, 23:56 …; `F17` 10:00/13:40; `F18d` 17:54; `F32` 22:55; `T3` 19:40; `A7` 20:39 — each $0.008–0.020, 12–34 turns for re-checking a byte-identical build) and non-landed `NEGATIVE`/`BLOCKED`/`PARTIAL` with nothing merged (`F20` 11:23/11:41, `F22` 12:31, `F22b` 14:15, `F24` 18:37-verifier, `F25b` 18:37 BLOCKED verifier 36 turns/$0.027/38 tools/14 min, `F26` 20:10, `F30b` 21:25, `F31` 21:13, `F34` 23:28). The `F25b` BLOCKED verifier alone cost more than several landed workers. Nothing from a non-landed branch is built on — there is no commit for the next ticket to cite — so these verifications buy no forward information.

The per-pass deltas are independent one-family residues; there is no evidence any pass needed same-day bisection against its sibling pass.

## 3. New tool `tools/naming_check.sh` for the naming-ticket quadruple workers hand-run every time

**Observed pattern.** 4 of the last 12 Results are pure naming passes, each hand-running the same four checks and pasting the same three numbers: `F23` custom.rs (299→0 bare, `.text` byte-identical, `.gba` 541272B cmp-l 49 panic-lines, full table unchanged), battle.rs (110 lines/38 values→0, `.text` md5-identical, 553172B cmp-l 29), actor.rs `ffe8bac` (39→0, `.gba` md5 `dc4892e8…`, cmp 0), results.rs `b1bac4e` (81→0, `.text` md5-identical, `.gba` cmp 14 panic-line bytes). Worker cost on these: 57–116 turns, $0.026–0.119 — mechanical measurement dominating a zero-behavior change. The `// provenance:`/`// canon:`/`// unnamed:` tagging rule (AGENTS.md) is grep-checkable and should be part of the same script.

**Spec** (new tool; usage line is the interface):

```
usage: bash tools/naming_check.sh <branch-or-worktree> [--base main] [--full-table]
  Counts bare literals in the diff (must be 0; lists offenders with file:line),
  builds release in both trees (own CARGO_TARGET_DIRs), compares .text md5 and
  .gba size/cmp (PASS iff identical or diff confined to rodata panic-line bytes),
  runs the full harness table (default: spot rows wave,window,mettaur,popup,buster,
  result,field; --full-table runs all 60). Exit 0 prints the three Result numbers;
  exit 1 lists the failing check. Coordinator step 4 accepts its PASS in place of
  per-row --expect for naming-only branches; land.sh calls it when the branch
  touches no .s / fixture / harness semantics (diff stat is src/*.rs comments/idents only).
```

Reference implementation shape (human session writes it; ~60 lines): `git diff --unified=0 base...branch -- src/ | grep -E '^\+' | grep -E '(0x[0-9a-fA-F]+|[0-9]+)' | grep -v 'provenance:\|canon:\|unnamed:'` for the bare count; two `cargo build --release` + `gbafix.py` + `cmp -l` + `md5sum` for the artifact check; `harness.py --only wave,window,mettaur,popup,buster,result,field --no-gallery` for the spot table. Worker role text then drops to "run `naming_check.sh`, paste its output" for tickets tagged naming-only.

**Metric it should move.** Worker turns/cost on naming-class tickets: from 57–116 turns/$0.026–0.119 (`F23`/battle/actor/results rows) to <25 turns (one script + paste). Next review's ledger shows naming rows at the bottom of the turns column with identical PASS strings.

**Risk.** A script that blesses "panic-lines only" diffs could mask a real rodata change if the allowlist drifts (the `cmp -l` range check is the load-bearing line). Mitigated by keeping the invariant the diff already keeps: any `.text` difference is FAIL, and any `.gba` difference outside the panic-line rodata window is FAIL — the script exits 1 and the ticket falls back to the full manual path.
