# SCOPE: the whole BN6 (Falzar ROM) battle engine, and how "done" is measured

The user (2026-09-14): "The purpose of this project is to replicate the bn6 battle engine ... all the chips, viruses,
Navis, program advances, MegaMan transformations, UI, and so on." This file is the completion ladder. Every item is
done only when it has (a) a canon recording (a scenario in tools/states.py), (b) its routines ported from the
disassembly with citations, (c) state parity on the trace (tools/trace.py: no divergence on the scenario), and
(d) pixel parity (0 differing pixels on the scenario's frames). The counts below are placeholders until T10
regenerates the per-item tables from the ROM's own tables (tools/inventory.py).

Decisions (the user, 2026-09-14 14:00): audio IN scope; netbattle IN scope; Gregar-exclusive content in scope in
principle, but no Gregar disassembly exists (dism-exe/bn6f covers Falzar only, sha1 0676ecd4...), so M11 starts
with a measured ROM diff against bn6f's symbols once the user provides the Gregar ROM (never tracked).
