The chip-select cursor walking OK to the fifth slot, real ROM left and this build right: 170 frames, 0 pixels. Everything the script drives -- the cursor, the card, the name -- was exact for a long time while the highlight bracket's blink stayed one frame out, and that was written off as unfixable: the blink counts from the window's opening, the real side is a save state already open, so the two clocks were said to have no shared origin. Reading the routine instead of guessing at it settled it. The phase is (counter >> 3) & 1 off a frame counter in the window's own struct, window-relative on both sides -- the save state's value simply is not zero. The missing frame turned out to be ours: our slide-in reached its open state one frame after the real ROM's does, invisible everywhere except in that blink.
