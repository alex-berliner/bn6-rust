bn — Mega Man Battle Network 6, rebuilt in Rust

A Game Boy Advance ROM that re-creates the game's battle system and is compared against the real cartridge frame by frame, pixel for pixel. Everything this project publishes is listed below.

  • Play it in the browser The current build running in an emulator on this page, with touch controls on a phone and the keyboard on a desktop.
  • How it works, one slide at a time A scrolling feed of short slides, one part of the code per slide: what it does, the lines that do it, and plain words for both.
  • Project blog Longer posts, newest first, on the milestones: what was built, what it broke, and what was learned pulling the original game apart.
  • Before and after gallery Every comparison as an animation: the real game on top and this build below, with the caption for what changed and how far off it was.
  • Screenshot log A dated record of how the screen has looked along the way, from the first blank field to a full battle.
  • Download the ROM bn6-rust.gba The full build as a .gba file, to run in any emulator or on hardware.

    Packed —. Smaller single-purpose demo builds are in roms/.

  • Source code on GitHub The Rust for the ROM, the tools that pull the art out of the original, and the test that does the pixel comparison.
  • Disassembly notes A fork of the community disassembly of the original game, on the branch bn-notes, where what this project works out about a routine is written down.
